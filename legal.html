Privacy notice

Claim Check does not collect personal data. The Claim Check pages do not set cookies, run analytics, show advertising, use session replay, or include tracking pixels or third-party embeds.

What happens when you use the bookmarklet

The bookmarklet runs in your browser. It reads the visible text of the page you are on and builds the findings panel locally. It does not send the page text, the page address, or the findings to us or to any third party. It loads its own code from this site; that is an ordinary request to the hosting provider.

Hosting

This site is served by GitHub Pages. GitHub may process standard request data such as an IP address, browser user agent, and requested URL under the GitHub General Privacy Statement. The Claim Check project does not receive or use those server logs.

External links

Links to EUR-Lex, the European Commission, GitHub, and React Bits leave this site. Those sites have their own privacy and cookie practices. The corpus script runs locally on files you save; it does not fetch pages or upload them.

Children, sale and sharing

The site is not directed to children under 13 and does not knowingly collect information from them. There is no personal information to sell or share, and no targeted advertising to opt out of. Because no personal data is stored, there is no access, correction, deletion or portability request for us to fulfil; questions can be raised through the contact link below.

Accessibility statement

The checker targets WCAG 2.2 Level AA. It is a small static page with semantic landmarks and headings, a skip link, visible keyboard focus, keyboard-operable controls, text contrast above the AA thresholds, and a layout that reflows on narrow screens. The main page stops transitions and animations when the visitor prefers reduced motion.

Known limitations

  • The motion showroom is an experimental gallery of 50 third-party React Bits components. Some canvas, WebGL, cursor and animation tiles may depend on a pointer, may not be fully described to assistive technology, or may not honour reduced-motion preferences. It is not part of the checker.
  • The findings panel is a labelled dialog that appears after the bookmarklet runs. It moves focus to its Close button, supports Escape, and does not trap focus, so the page underneath remains reachable.
  • No manual audit with assistive-technology users has been completed, and the automated test suite checks the scanner, not WCAG conformance. This statement is a target and a list of known limits, not a claim of certification.

If something is inaccessible, open an issue with the page and the assistive technology you used: Claim Check issues. We will try to fix it.
