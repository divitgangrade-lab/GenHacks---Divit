Claim Check

On 27 September 2026, the EU blacklisted generic green claims. This marks them on the page you are shopping on, and names the rule each one breaks.

Use it on a real page

Drag this button to your bookmarks bar. On any product page, click it. The button is the whole program, one line of JavaScript that loads the scanner from this site, and the page text never leaves your browser.

Check this page

Bookmarklets do not run on browser-internal pages, and some sites block them. Where it can, the bookmarklet leaves a short notice linking back here; if the page refuses JavaScript entirely, no bookmarklet can speak. Run it on this page and it will also flag the rule table below, which quotes the banned phrases on purpose.
